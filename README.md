# 🎂 Система для дня рождения

Сайт для 5 устройств: 4 планшета команд + ноутбук именинников (пульт).
Всё хранится в Google-таблице, сайт лежит на GitHub Pages.

## Как это устроено

- **Сайт** (`index.html`, `js/`, `css/`) — статический, на GitHub Pages.
- **Бэкенд** (`apps-script/Code.gs`) — скрипт внутри Google-таблицы. Читает листы «Группы», «План»,
  пишет ответы и баллы, хранит общее состояние (что сейчас на экранах, сбор и т. д.).
- Устройства опрашивают таблицу раз в 2 секунды, поэтому команды пульта доходят до планшетов за 2–4 секунды.

## Подключение таблицы (один раз, ~5 минут)

1. Откройте таблицу → **Расширения → Apps Script**.
2. Удалите всё в `Code.gs` и вставьте содержимое [`apps-script/Code.gs`](apps-script/Code.gs).
3. В первой строке поменяйте `ADMIN_PIN = '0000'` на свой PIN для пульта. Сохраните (💾).
4. Выберите функцию `setup` в списке сверху → **Выполнить** → разрешите доступ к таблице.
   Появятся листы «Настройки», «Факты», «IQ вопросы», «IQ результаты», «Ответы команд», «Правильные ответы».
5. **Развернуть → Новое развертывание** → тип «Веб-приложение»:
   - Выполнять от имени: **Меня**
   - У кого есть доступ: **Все**
6. Скопируйте URL веб-приложения (заканчивается на `/exec`) и вставьте в `js/config.js` → `API_URL`.

> Если поменяете код скрипта — **Развернуть → Управление развертываниями → ✏️ → Версия: новая**,
> тогда URL не изменится.

## На празднике

- На каждом планшете откройте сайт → выберите свою команду → «Нажмите, чтобы начать»
  (это включает звук тревоги-кнопки и не даёт экрану погаснуть). Лучше добавить сайт на главный экран.
- На ноутбуке: «Пульт именинников» → PIN.
- Громкость на планшетах — на максимум, беззвучный режим — выключить.

### Пульт

| Раздел | Что делает |
|---|---|
| 🚨 Тревога-кнопка | В любой момент дня: сирена и кнопка «ЖМИ!» на всех планшетах. Первая нажавшая группа получает баллы в выбранной дисциплине |
| 🎛 Пульт | Что показать на планшетах, какие устройства онлайн |
| 🏆 Баллы | Баллы групп по дисциплинам (+ / −), показать таблицу на планшетах, скрыть от гостей |
| 🗓 План | Отметить, какой пункт плана идёт сейчас |
| 🃏 Факты | Добавлять факты, выбирать, кто открывает следующую ячейку, показывать ответ |
| 🧠 IQ-тест | Запустить тест (одна попытка на группу), сбросить попытку, показать рейтинг |
| 🎯 Испытания | Запустить испытание для всех групп, закрыть приём, показать ответ, начислить баллы |
| 🎯 Своя игра | Вставить ссылку на лобби и показать её (с QR-кодом) |

Ничего не запускается само — всё по кнопке с пульта.

### Таблица

- **Настройки**: имена именинников, минуты на IQ-тест.
- **Баллы**: строки — дисциплины, колонки — группы. Можно править прямо здесь, итог считается сам.
- **IQ вопросы**: можно менять вопросы, варианты, правильную букву и баллы.
  Меню таблицы **🎂 ДР → Загрузить вопросы IQ (11 класс)** заменяет лист на вопросы из `Code.gs`.
  Баллы IQ пишутся в лист «4 комнаты», колонка «Айкью тест».
- **Испытания**: одна строка — одно испытание. Тип:
  - `выбор` — варианты через `;` (например `Правда;Ложь`);
  - `текст` — свободный ответ, правильных вариантов может быть несколько через `/`;
  - `число` — баллы получает самый близкий ответ;
  - `слова` — «4 слова»: в «Вариантах» слова групп по порядку (`Жираф;Пылесос;Свадьба;Космос`).
    Каждая группа видит на планшете только своё слово, группы по очереди выходят его показывать
    (на пульте можно отметить, кто сейчас показывает). Каждая группа пишет итоговое предложение
    из всех слов; верное (колонка «Правильный ответ») — «Баллы».
  - `шпион` — «Шпионы»: группы по одной заходят в комнату (на пульте отмечается, кто внутри), у одной
    группы сценка отличается. Группы задают вопросы и голосуют на планшетах, кто шпионы (за себя нельзя).
    «Правильный ответ» — группа-шпионы (можно выбрать на пульте). Угадавшим — «Баллы»,
    шпионам — «Баллы», если их не вычислило большинство.
  - `кейс` — «Кейс с деньгами»: группы по одной заходят в комнату и берут из кейса сколько хотят,
    сумму пишут на планшете (или ведущие вписывают её на пульте). «Баллы» получает группа, взявшая
    больше всех; если все взяли поровну — все.

  Варианты и слова для «4 слов» можно менять и в таблице, и на пульте в карточке испытания.
  «Секунд» — таймер на ответ (0 — без таймера), «Дисциплина» — куда начислять баллы.
- **Ответы испытаний**: колонка «Проверка» — `+` / `-`, чтобы засчитать вручную (или на пульте).

## Локальная проверка без Google

```bash
node dev/server.js
```

Откроется на http://localhost:8787 с тестовыми данными (PIN `0000`).
